# Admissions

## Admission Process

- **Mode:** Online, through the official college website (ethirajcollege.edu.in > Admissions > Apply Now)
- **Steps:**
  - Register with mobile number and email ID
  - Log in with registration credentials and fill in the online application form
  - Fill 'Name' exactly as per the 12th mark sheet; Tamil name can be entered using tools like tamiltyping.in
  - CBSE board students need not give Part I language mark; other board students can add subjects via 'Add Row'
  - Choose correct subjects studied in +2 from the given options
  - Upload a recent passport-size photograph (max size 100kb, jpg/jpeg only; school-uniform or selfie photos not accepted)
  - Upload required documents (12th mark sheet, UG semester mark sheets as a single PDF, Community Certificate, TANCET hall ticket/mark sheet for applicable PG courses, etc.)
  - Pay the application/registration fee online and proceed
  - Download and save a copy of the submitted application form
  - A unique application reference number is generated and communicated via SMS and email
- **Important Notes:**
  - Application, once saved, cannot be edited
  - A candidate can apply for any number of courses across Aided and Self-Supporting streams
  - All communication is sent only to the email ID and mobile number provided at the time of application
  - Recommended browser noted in some years: Mozilla Firefox for logging into the college website

## Eligibility Criteria

- **UG:** Pass in 10+2 (or equivalent) from a recognised board, with a minimum aggregate as specified per course; subject-specific requirements apply (e.g., B.Com. requires Accountancy/Commerce/Business Studies + Mathematics/Business Mathematics + Economics/Computer Science).
- **PG:** Graduation in the relevant or allied discipline from a recognised university
- **MBA MCA:** Graduation in any discipline (for MBA) / with Mathematics background (for MCA), plus a valid TANCET score where applicable

## Documents Required

- 12th standard mark sheet
- UG semester mark sheets (combined as a single PDF, for PG applicants)
- Community Certificate
- TANCET hall ticket (for MBA/MCA applicants)
- TANCET mark sheet (for MBA/MCA applicants)
- Recent passport-size photograph

## Selection Procedure

- **UG:** Admission based purely on merit - the marks secured in the qualifying 10+2 examination. No entrance test for general UG admission.
- **PG:** Admission based on merit (marks in the qualifying UG examination)
- **MBA MCA:** Admission based on TANCET score followed by counselling, in addition to graduation eligibility
